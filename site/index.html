Why not an online unlocker?

The usual answer is to upload the file — and the password — to a website you have never heard of.

Most “unlockers” open a PDF with an empty password and re-save it without the permission flags. That is a bypass, not a decryption. This tool refuses unless you supply the owner password.

What it will and will not do

Enforced in code, not promised in a README. Every refusal has a test proving it.

✓ Decrypts what you can authenticate

Supply a password the file’s own verifier accepts, and it writes a new, unencrypted copy. The original is left untouched.

✕ Never guesses a password

No recovery, no brute force, no dictionary, no retry loop. A wrong password exits 3 and writes nothing.

✕ Never bypasses encryption

Permission flags come off only with the owner password and an explicit --remove-restrictions.

✕ Never touches DRM or IRM

Information Rights Management, Adobe.PubSec and ebook DRM are reported and left alone.

Nothing installed, parsers contained. Multi-arch, non-root, cosign-signed.

docker run --rm -v "$PWD:/data" \
  --user "$(id -u):$(id -g)" \
  ghcr.io/jayanth-reflex/file-password-remover \
  inspect /data/report.pdf

Standalone

No Python at all. macOS, Linux and Windows bundles on the releases page. They are unsigned — verify the checksum.

Not on PyPI yet. pip install file-password-remover will be the install once the project is published. The name is reserved by nobody — including us — so do not trust a package of that name appearing before this note is gone.

How you know it actually worked

A success message is printed only after the written file has been re-read from disk.

1. Capture

Content invariants are taken from the input: page counts, per-page content-stream digests, per-entry SHA-256.

2. Write atomically

Output goes to a 0600 temp file in the destination’s own directory, is fsync’d, then renamed into place.

3. Re-open

The file is read back from disk and proved to be unprotected — not assumed from the return value of a library call.

4. Compare

The invariants are recomputed and checked against the ones captured from the input.

5. Or fail loudly

If anything mismatches, the output is scrubbed and the run exits 9. A file that cannot be proved good never reaches the name you asked for.

No password on argv

There is no --password VALUE flag. Command lines are readable by every process and land in shell history. Use --password-stdin.
